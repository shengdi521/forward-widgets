# Forward Widgets

ForwardWidget 全影视在线搜索模块：

- B站影视搜索：电影、电视剧、番剧、国创、综艺、纪录片（WBI 签名搜索 + 官方 MP4 播放）
- 爱奇艺影视搜索：电影、电视剧、动漫、综艺、纪录片（官方 HLS 播放）

## 订阅地址

```text
https://raw.githubusercontent.com/shengdi521/forward-widgets/main/forward-widgets.fwd
```

在手机或 iPad 的 Forward 中添加上述订阅地址，即可看到两个独立模块。

## Cookie 安全

仓库和模块源码不包含任何账号 Cookie。请分别在各设备的 Forward 模块参数中填写自己的完整 Cookie；不要将 Cookie 提交到 GitHub、Issue 或聊天记录。

模块仅调用平台官方接口，过滤短视频、用户投稿和站外跳转。点击详情中的正片或分集后，Forward 会动态加载账号当前有权观看的官方播放线路；会员资格、地区限制和试看范围均由平台服务器判定，不绕过 DRM 或会员权限。
